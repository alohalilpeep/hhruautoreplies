# hh.ru autoreplies

Автоотклики на hh.ru через профиль BitBrowser и Playwright.

Скрипт цепляется к уже запущенному профилю BitBrowser по CDP, поэтому работает
внутри твоего залогиненного окружения: свой отпечаток, свои куки, свой прокси.
Отдельный `playwright install` не нужен — браузер берётся из BitBrowser.

## Установка

```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`: как минимум `PROFILE_ID` и `SEARCH_URL`.

## Запуск

```bash
venv/bin/python hh_autoapply.py
```

По умолчанию `DRY_RUN=True` — скрипт обходит выдачу и логирует, что бы он сделал,
но не откликается. Убедись, что сухой прогон даёт осмысленные статусы, и только
потом ставь `DRY_RUN=False`.

## Как собрать SEARCH_URL

Проще всего настроить поиск на hh руками и скопировать URL из адресной строки.
Полезные параметры:

| Параметр | Пример | Что делает |
|---|---|---|
| `text` | `DevOps OR SRE OR "системный администратор"` | запрос; `OR` обязательно капсом, фразы из двух слов в кавычках |
| `search_field` | `name` | искать только в названии вакансии, а не в описании |
| `experience` | `between3And6` | ещё: `noExperience`, `between1And3`, `moreThan6` |
| `work_format` | `REMOTE` | удалённая работа |
| `area` | `113` | 113 Россия, 1 Москва, 2 Санкт-Петербург |

Без `search_field=name` запрос ловит слова в теле описания, и в выдачу лезут
вакансии, где DevOps просто упомянут в требованиях.

## Статусы

Результат каждой вакансии пишется в SQLite `hh_responses.db`:

| Статус | Значение |
|---|---|
| `applied` | отклик отправлен и подтверждён |
| `already` | на вакансию уже откликались раньше |
| `no_button` | кнопки отклика нет |
| `external` | отклик ведёт на сайт работодателя, пропущено |
| `questions` | вакансия с вопросами или тестовым, оставлено на ручной разбор |
| `dry_run` | сухой прогон |
| `error` | исключение на этой вакансии |
| `unknown` | кликнули, но подтверждение не нашли |

Вакансии со статусом `dry_run` и `error` не считаются обработанными и будут
перепроверены на следующем запуске, остальные пропускаются.

## Лимиты

`DAILY_LIMIT` — свой лимит откликов в сутки, считается по базе. Отдельно скрипт
ловит лимит самого hh и останавливается, если тот исчерпан. После каждого
отклика пауза 20-60 секунд, между остальными переходами 3-8.

## Что лежит локально и не коммитится

`.env` (ID профиля и личные настройки), `hh_responses.db` (история откликов),
`venv/`.
